# داستان‌ساز 🎭📖

نسخه مستقل و آزمایشی برنامه داستان‌ساز.

## امکانات نسخه 1
- ساخت داستان فارسی با موضوع، ژانر، رده سنی، پند، نتیجه و نام شخصیت
- ساخت شعر با موضوع، سبک، قالب و نام دلخواه
- خواندن اثر با Text-to-Speech فارسی گوشی
- دریافت موضوع با فرمان صوتی
- ذخیره و کتابخانه آثار
- اتصال مستقیم به Gemini با secret به نام `GEMINI_API_KEY`

## هدف نسخه‌های بعد
داستان‌یار مکالمه‌ای، چندصدایی شخصیت‌ها، جلد تصویری، ادامه خودکار قسمت‌ها و حالت‌های صوتی پیشرفته.
